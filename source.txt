int calc(int* arr, int size)
{
  int ans = 0;
  for (int i = 1; i < size; i++)
  {
    ans += arr[i] - arr[i-1];
  }
  return ans;
}

Функция calc вычисляет сумму разностей соседних элементов массива.
Время работы O(n) где n - размер массива
Используемая память O(1) так как задаётся одна переменная ans не зависимо от длинны массива
